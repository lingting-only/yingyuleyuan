# 词库动态导入优化

## 概述
将 [wordbank.ts](file:///d:/codeup/yingyuleyuan/src/lib/wordbank.ts) 中写死的静态导入 `contentMap` 改为基于 `import.meta.glob` 的动态导入，使“新增词库 = 新建 `<id>.json` + 在 `index.json` 追加一条”，无需再改动 `wordbank.ts`。同时把已有的 `it-words.json` 接入生效（作为 I T/计算机领域词汇词库）。

## 现状分析
- 构建工具：Next 16，[next.config.ts](file:///d:/codeup/yingyuleyuan/next.config.ts) 未指定打包器。Next 16 的 `next dev` 与 `next build` 默认使用 **Turbopack**。
  → 必须用 Turbopack 兼容的动态导入 API `import.meta.glob`（Vite 风格），**不能**用 webpack 的 `require.context`。
- 数据形态：每个词库 JSON 自带 `id` 字段，且含 `words[]` 或 `sentences[]` 之一，据此可自动推断类型与内容。
  - `pep-*.json` / `it-words.json` → `{ id, words: [...] }`
  - `t1/t2/t3.json` → `{ id, sentences: [...] }`
- 元信息（titleCn / grade / description / 顺序）只在 `index.json` 中，保存为单一清单。
- `wordbank.ts` 当前逐文件静态 `import` + 手写 `contentMap`（L5-L12、L41-L49），新增词库必须改这里——正是这次的痛点。
- `it-words.json` 已存在但未导入 `wordbank.ts` 也未登记 `index.json`，目前不生效。

## 建议改动
### 1. `src/lib/wordbank.ts` —— 动态导入内容
- 删除 7 行静态 JSON 导入（`pep3..pep6`、`t1..t3`），仅保留 `import indexJson from './wordbanks/index.json'`（index 仍是清单）。
- 新增 glob 动态加载，并按文件名 `id` 与 `words/sentences` 字段构建 `contentMap`：

```ts
const bankModules = import.meta.glob('./wordbanks/*.json', {
  eager: true,
  import: 'default',
}) as Record<string, unknown>;

type RawBank = { id?: string } & Partial<{ words: WordBankItem[]; sentences: TypingSentence[] }>;

// 依据 index.json 的 id 做内容映射：新增词库只需新建 <id>.json + 在 index 登记
const contentMap: Record<string, BankContent> = {};
for (const [key, mod] of Object.entries(bankModules)) {
  const id = key.split('/').pop()!.replace(/\.json$/, '');
  const r = mod as RawBank;
  if (Array.isArray(r.words)) contentMap[id] = { type: 'word', words: r.words };
  else if (Array.isArray(r.sentences))
    contentMap[id] = { type: 'sentence', sentences: r.sentences as TypingSentence[] };
}
```
- `index.json` 也在 glob 范围内，但它无 `words/sentences` 字段会被自动跳过，无需特判。
- `wordBankIndex`、`getBankContent`、`isWordBankId`、`isWordItemId`、`findPracticeById`、`findBankIdByItem`、`wordToSentence`、`bankToPracticeQueue` 等逻辑保持不变（继续使用 `indexJson` + `contentMap`）。

### 2. 新增 `src/types/import-meta.d.ts` —— 提供 `import.meta.glob` 类型（供 `tsc` 通过）
> 文件无 import/export 顶层语句（全局脚本），以 interface 声明合并 `ImportMeta`：
```ts
interface ImportMeta {
  glob<T = unknown>(glob: string, opts?: { eager?: boolean; import?: string }): Record<string, T>;
}
```

### 3. `src/lib/wordbanks/index.json` —— 登记 `it-words`
在 `pep-6` 之后追加一条（I T 领域词汇）：
```json
{
  "id": "it-words",
  "type": "word",
  "grade": "IT 领域",
  "titleCn": "IT 英语词汇",
  "titleEn": "IT Vocabulary",
  "description": "计算机与信息技术常用词汇"
}
```
