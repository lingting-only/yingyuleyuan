# 打字页暂停 + 模糊“按任意键继续”提示

## 需求
页面切换后（浏览器切走/失去焦点），打字练习静止、计时暂停；返回后暂停状态保持，内容做模糊隐藏，提示【按任意键继续】；按下任意键后恢复练习并重新计时。

## 现状分析
- [page.tsx](file:///d:/codeup/yingyuleyuan/src/app/page.tsx) 已有 `isPaused` 状态（L54），且已接好两处逻辑：
  - 计时 effect（L118-L125）：`isPaused` 为 true 时停止累加计时。
  - `handleKeyPress`（L188-L249）：`isPaused` 为 true 时直接 return，不响应输入。
- 但 `grep isPaused` 确认：**全文件从未把 `isPaused` 置为 true**，暂停功能形同虚设，也未做模糊提示与恢复逻辑。
- 全局 keydown effect（L305-L338）负责快捷键与打字输入，是接入“任意键恢复”的最佳位置。

## 改动方案（全部集中在 `src/app/page.tsx`）

### 1. 监听页面切走/失去焦点 → 置为暂停
新增一个 effect：监听 `visibilitychange` 与 `blur`，当页面隐藏或窗口失去焦点时 `setIsPaused(true)`。
- `visibilitychange`：`document.hidden === true` 时暂停。
- `blur`：window 失焦时暂停。
- 关键：**不**在 `visible`/`focus` 时自动恢复——恢复只能依靠按键（符合“按任意键继续”）。
- 需加一个 ref（如 `typingFocusedRef` 或直接判断）避免“切走后又点回”与按键恢复之间重复触发造成闪烁；最简单做法：只有 `!isPaused` 时才置为 true。

### 2. 任意键恢复
在全局 `handleKeyDown`（L306-L334）的最前面（输入框/textarea 守卫之后）插入：
```ts
if (isPaused) {
  e.preventDefault();
  setIsPaused(false);
  return; // 该键只用于恢复，不作为输入
}
```
- 同步把 `isPaused` 加入该 effect 的依赖数组（L338）。
- 恢复后计时 effect（L118-L125）因 `isPaused` 变 false 会自动重新开始计时。

### 3. 暂停时的模糊隐藏提示
- 给主内容容器（L520 的 `<div className="flex-1 flex flex-col ..."`）加 `relative`。
- 在该容器末尾、`</div>` 之前，新增条件渲染对照层：
```tsx
{isPaused && (
  <div className="absolute inset-0 z-30 flex flex-col items-center justify-center gap-3 backdrop-blur-md bg-white/50">
    <p className="text-xl md:text-2xl font-semibold text-slate-700">按任意键继续</p>
    <p className="text-sm text-slate-500">页面已暂停</p>
  </div>
)}
```
- `backdrop-blur-md` + 半透明背景实现“静止/模糊隐藏”；居中提示【按任意键继续】。

## 决策与说明
- 恢复动作：按下任意键仅恢复（`return`），不把该键当作本次输入，避免误字。
- 暂停范围只覆盖主内容练习区（句子/键盘/进度），顶栏保持可操作，符合“打字页面静止”。
- 不处理错题/进度记录（`recordSentenceCompletion` 只在 `completed` 时触发，不涉及暂停）。
- 不新增第三方依赖，仅用现有 React hooks 与 Tailwind 工具类。
